# 🚦 Semáforo Inclusivo & Acessível

Este projeto consiste em uma aplicação web interativa de um semáforo de trânsito desenvolvido com foco em **acessibilidade urbana e inclusão**. O projeto foi organizado utilizando a metodologia ágil **Kanban**, com acompanhamento diário via quadro físico e controle de versão no GitHub.

## ♿ Recursos de Acessibilidade Implementados

* **Sinalização Sonora / Áudio:** Avisos de áudio indicando as mudanças de estado da cor para deficientes visuais.
* **Modo Alto Contraste:** Interface adaptada com cores vibrantes sobre fundo escuro para daltônicos e pessoas com baixa visão.
* **Extensão de Tempo de Travessia:** Botão funcional para solicitar tempo adicional de travessia, atendendo idosos e pessoas com mobilidade reduzida.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação e elemento `<canvas>`)
* **CSS3** (Estilização responsiva e modo alto contraste)
* **JavaScript (ES6+)** (Lógica dos ciclos de tempo, controle do Canvas e emissão sonora)
* **Git & GitHub** (Controle de versão e histórico diário de commits)
* **Kanban Físico** (Gestão visual de tarefas e controle de WIP)
